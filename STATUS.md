# STATUS.md — Car Repair, in Plain English

Last updated: 2026-11-07

## What was built

A beginner-friendly guide that decodes car repair estimates for people who dread the service desk: Markdown docs plus a fully static HTML site.

**Docs (`docs/`, 7 pages, ~4,000 words):**

- `index.md` — start here; how to use the guide, what's inside, the "education, never diagnosis" premise.
- `estimates.md` — decodes every estimate line item (diagnostics fee, flat-rate labor, core charges, shop supplies, haz waste fees, taxes) with a worked example, red-flag/green-flag table, and an escape-hatch phrase.
- `obd-codes.md` — how to read P/B/C/U + digit families, table of commonly seen codes with urgency, the "code names a neighborhood, not a culprit" trap, clearing-code rules, flashing vs. solid light.
- `questions.md` — copy-paste question templates organized by moment (before approval, price feels high, second opinion, after work done, safety-not-negotiable list, phrase library for hard moments).
- `ai-translator.md` — a 3-pass free-AI prompting method to translate a quote into plain English, with explicit AI can/can't boundaries, and a repair-now vs. wait decision framework table.
- `maintenance-primer.md` — intervals worth memorizing, a 10-minute monthly walk-around, DIY difficulty ladder, driving habits, glossary.
- `about.md` — printable second-opinion script, the plain-spoken disclaimer, credits, and reuse notes (MIT).

**Static site (`site/`):** 7 HTML pages + one stylesheet, generated by `tools/build.py` from the docs. Shared sticky nav, footer disclaimers, `styles.css` theme (no fonts/CDN/JS). **Zero tracking, zero cookies, zero ads, zero affiliate links, zero external requests — the site works fully offline.**

**Tooling:**

- `tools/build.py` — Python build script (uses the `markdown` package; includes a minimal stdlib-only fallback converter if it's missing). Rewrites internal `.md` links to `.html` at build time.
- `Makefile` — `make build`, `make test`, `make serve`, `make check`, `make clean`.
- `tests/test_build.py` — 10-test stdlib-`unittest` suite.
- `LICENSE` (MIT, copyright exactly `Copyright (c) 2026 Asdale Dynamics, LLC`), `README.md` (credits Asdale Dynamics, LLC), `.gitignore`.

## How to run it

```bash
make check            # build + tests
make serve            # build + serve at http://localhost:8000
# or, without make:
python3 tools/build.py
python3 -m unittest discover -s tests -v
python3 -m http.server 8000 --directory site
# or simply open site/index.html in a browser (no server required).
```

## Known gaps

- **Content:** prices/mileage intervals are explicitly labeled as typical ranges, not quotes; a region-specific price appendix could be added later. Reader corrections (missing jargon, bad advice) are the intended contribution channel.
- **Accessibility:** tested via well-formedness parsing and semantic markup, but not with a live screen-reader pass; color contrast is high but not formally audited.
- **Fallback converter:** the stdlib fallback in `build.py` is intentionally minimal (headings, lists, tables, fences, bold/italic/links); the primary path relies on the `markdown` package.
- **No search:** a static client-side search page was skipped to keep the site dependency-free; ILIKE-nav works fine at this size.
- **Sibling projects:** `car-buying-calm-guide` and `free-car-care-pack` are cross-referenced in the README only; no links between repos exist yet.
- Git repo is initialized locally with a single commit; nothing pushed or published anywhere (per instructions).
